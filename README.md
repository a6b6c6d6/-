# lzsb-smart-water-sticker

在 linux.sb 论坛自动回帖的油猴脚本。流程就是：抓帖子内容 → 调你自己的 AI → 生成回复 → 填进回复框。

名字起得叫"水贴专用"，说白了就是个 AI 回帖小工具，省得每次手打。别真拿去刷屏就行。

## 怎么用

先装个 [Tampermonkey](https://www.tampermonkey.net/)，然后把仓库里的 `linux.sb-ai-reply.user.js` 装上。打开任意帖子页，右下角会多出来一个"水贴专用"按钮。

点开之后：

1. 选抓取范围（只抓首楼 / 抓楼主全部发言 / 抓全帖）
2. 点"抓取并生成回复"
3. 生成的内容能在面板里改，改完点"填入编辑器"
4. 点论坛的"回复"发出去

## 第一次用要先配

面板的"设置"里填三个东西：

| 项 | 填什么 |
| --- | --- |
| baseUrl | AI 接口地址，比如 https://api.openai.com/v1 |
| apiKey | 你的 key |
| model | 模型名，比如 gpt-4.1-mini |

接口格式支持两种（responses 和 chat/completions），默认 responses。key 只存在你自己浏览器里，不会传出去。

## 几个要注意的点

- "填入编辑器"得先登录 linux.sb，没登录页面只有个"登录后回复"，没有输入框。
- 脚本里 `@connect` 是 `*`，为了兼容各种自建接口。介意的话改成你自己的接口域名。
- 抓取内容默认带发言人标识，不想带可以在设置里关掉。
- 默认会抓正文里的图片一起喂给模型（多模态），比较费 token；模型不支持看图、或不想费 token，就在设置里把「抓取正文图片」关掉。
